# 小程序 UI 纠偏交付

仅修正用户三张真机截图指出的 UI；保留暖色、插画及既有数据/分析规则，不迁移框架、不加入新依赖。

## 修正与根因

- 全局按钮：清除微信 button::after 默认描边，重置默认 auto margin；原 border:0 只作用于本体，造成二重边框，上一轮 DOM 模拟没有覆盖原生伪元素。
- 账号与同步：状态独立一行；登录为主操作，同步两项横排，草稿入口收为文字按钮。移除三列 grid，直接使用微信可用的 flex，避免转换后布局错位。五个原有动作及鉴权/同步函数未变。
- 产品列表：产品名本身可点击进入详情，取消每项重复的「查看产品详情」。选择按钮仍独立，只名称点击不会改变已选状态。
- 分析与推荐：同一 Disclosure 布局、同宽说明入口、统一左右留白；内部条目不再描边/阴影/彩色边线，展开后同样平铺。默认折叠和优先顺序保持。
- 计数统一「共 N 项」，分组也使用「N 项」；分析总数按实际去重后展示条目计算。分析条目与皮肤情况仍是不同业务对象，不人为凑成相同数字。
- 标题栏绿色圆角矩形：纯旧装饰、没有功能。原编译脚本删除了 display:none 隐藏规则，却保留装饰本体，导致真机显露；现已从源码取消装饰及其隐藏规则，不再依赖后处理隐藏。
- 单标题 section-title 不再同时命中“最后一项元数据”样式；只有相邻第二个 Text 使用计数样式。主按钮与产品搜索框显式占满可用宽度；当前组合名称和品类分行。
